# Результаты экспериментов

Папка содержит результаты валидационных и тестовых запусков моделей.

В каждой папке отдельного запуска находятся:

- `summary.csv` — агрегированные метрики запуска.
- `samples.csv` — компактная таблица по отдельным генерациям.
- `samples.jsonl.gz` — сжатый JSONL-файл с полными сырыми результатами генераций.

Файлы `samples.jsonl.gz` являются сжатыми версиями исходных `samples.jsonl`.

## Валидационные запуски

- `base_val/` — базовая модель gpt-oss-20b.
- `dapo20_val/`, `dapo30_val/`, `dapo40_val/`, `dapo50_val/` — чекпоинты DAPO после 20, 30, 40 и 50 шагов обучения.
- `sb20_val/`, `sb30_val/`, `sb40_val/`, `sb50_val/` — чекпоинты DAPO+ShorterBetter после 20, 30, 40 и 50 шагов обучения.
- `sb50_add8_val/` — дополнительные 8 сэмплов для `sb50_val`; используются вместе с `sb50_val/` для расчета `sb50@24`.
- `dapo-cot20_val/`, `dapo-cot30_val/`, `dapo-cot40_val/`, `dapo-cot50_val/` — чекпоинты DAPO, обученные в CoT-режиме и оцененные в TiR-режиме.

## Тестовые запуски

- `base_test/` — базовая модель gpt-oss-20b на тестовом наборе.
- `dapo40_test/` — лучший DAPO-чекпоинт на тестовом наборе.
- `sb20_test/` — лучший DAPO+ShorterBetter-чекпоинт на тестовом наборе.
