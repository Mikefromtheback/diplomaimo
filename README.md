# Материалы к ВКР

**«Повышение качества решения математических задач олимпиадного уровня с помощью LLM с открытыми весами»**

Репозиторий содержит код, данные и результаты экспериментов, использованные в выпускной квалификационной работе.

В работе исследуется RLVR-дообучение `gpt-oss-20b` для решения олимпиадных математических задач в режиме Tool-Integrated Reasoning (TiR) с использованием Python-инструмента.

Реализовано обучение на основе DAPO с LoRA-адаптерами. Для повышения токенной эффективности рассуждений проведён анализ альтернативных подходов, по результатам которого выбран ShorterBetter и выполнена его адаптация к TiR-траекториям.

## Основные результаты

Тестовый набор: 30 задач, 16 генераций на задачу.

| Модель | Maj@16 | Pass@16 | Sample accuracy | Средняя длина, токены |
|---|---:|---:|---:|---:|
| Base | 60.0% | 76.7% | 41.0% | 18 446 |
| DAPO (dapo40) | **70.0%** | 76.7% | 42.7% | 19 911 |
| DAPO + ShorterBetter (sb20) | 66.7% | 76.7% | **43.8%** | **16 206** |

DAPO повысил Maj@16 с 60.0% до 70.0%, но увеличил среднюю длину генераций. Конфигурация DAPO + ShorterBetter достигла Maj@16 66.7% при сокращении средней длины на 12.1% относительно базовой модели.

Результаты получены на ограниченном тестовом наборе и требуют дальнейшей проверки на более широкой выборке.

## Структура репозитория

- `notebooks/01_finetune_kaggle.ipynb` — запуск обучения в Kaggle.
- `scripts/finetune_tinker.py` — основной скрипт обучения.
- `notebooks/02_tinker_to_peft.ipynb` — конвертация Tinker-адаптера в PEFT-формат.
- `scripts/merge_adapter.py` — слияние PEFT-адаптера с весами базовой модели.
- `notebooks/03_validate_nemotron.ipynb` — валидация Nemotron Nano 30B.
- `notebooks/04_validate_gpt_oss.ipynb` — валидация gpt-oss-20b.
- `notebooks/05_check_data_leakage.ipynb` — проверка отсутствия пересечений между обучающими, валидационными и тестовыми задачами.
- `data/` — валидационный и тестовый наборы задач.
- `results/` — результаты валидационных и тестовых запусков.

## Среда запуска
